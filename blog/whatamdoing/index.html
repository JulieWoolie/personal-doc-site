What's happening

This post is mostly to explain what I'm currently working and what my long term goals are with the projects. I've got a vision for a couple projects I want to work on, on the side, and a major project I wanna pursue as well.

First the big project!

1.Tetral, and the Argead Engine🔗

Tetral, is a programming language I'm developing. It's my first real attempt at writing a technical specification for a project as well (See it here.) The purpose of this project is twofold. I want it to serve as its own standalone thing, a type-safe scripting language that's familiar to people who use C, C++, Java or C#. Just something you can write and run with a single command, no complicated build system or anything.

The second goal of it is to serve as the embedded scripting language for a game engine I want to create, called The Argead Engine, named after the dynasty that Alexander The Great hailed from.

The engine itself I want to be open source, but the games I make with it, I won't open source.

Argead, in my vision, is a 2D and 3D engine, with the primary goal of running grand strategy games, like those made with the Clausewitz Engine by Paradox. That being said, I'll probably make a few engine test games with it, which will be regular games, just to test the engine and how it works.

But again, the true end goal of this engine, maybe years in the future, is to power a grand strategy game which will hopefully be somewhat on-par with Paradox titles. I know this will probably not happen, since there are whole teams working on those games, and I am one person, mostly a programmer with nearly no experience in shaders or art, but y'know. Blind optimism has gotten many in history to places that they would've never gotten to had they been realistic.

2.Side projects🔗

2.1.Carceres Dungeons🔗

Gods, I love giving things mythological and historical names for no reason other than aura.

Anyway, Hyperion Dungeons is a concept I had for a Minecraft server and accompanying website. Basically it's a rougelike server. You travel through levels of a randomly generated dungeon, and it records how far you got, how many mobs you killed, how much money you got, what items you found, etc.

Saves all of that stuff in a database, and you can view it on the website.

The idea was that you could also party up with others and do runs together.

I don't know if this idea has weight to it, but I find it fun.

Mostly this idea involved re-using the random dungeon generator code I wrote for ArcadiusMC, that never went anywhere, because we didn't work on it enough before we closed the server.

2.2.World Simulator🔗

I've always wanted to create some kind of world simulator project. What I mean by this is that I've always wanted to write a program that could somewhat realistically take in some parameters and create a world. Simulate the movement of tectonic plates, erosion and the climate for a period of time. All this while also simulating human population, politics, economics wars and so on.

All of that to generate a world history and to generate various maps.

I have finally started to work on that project, looking at research papers on procedural plate tectonics and stuff.

Also, I'm writing this project, Tetral and Argead all in pure C, because I'm just that cool.

3.Oh... Delphi🔗

Yeah, Delphi, my implementation of HTML/CSS/JS system for Minecraft with display entities to render the menus...

It's dead. I'm not working on it again. I might one day in the far future, but the problem is it does too much in a context where it doesn't need to.

A lot of features HTML/CSS/JS offers just isn't that useful for Delphi menus. I approached the idea from the wrong angle, while I think specifying the menus in XML with CSS styling was a decent idea, it doesn't really work. I should've gone for an approach like Microsoft's MAUI, which was designed for UIs specifically, and not the web.
